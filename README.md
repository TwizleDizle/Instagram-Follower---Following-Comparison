# Instagram Follower Following Comparison
A small python program which reads the provided json files from Instagram and compares the following and followers

# About
- Made in python 3.11.9
- Requires the *followers_1.json* and *following.json* files from Instagram

# Running
- Download .py and add to a folder
- Download .zip from Instagram: **Settings > Meta Account > Your Information and Permissions > Export Your Information**
- Extract *followers_1.json* and *following.json* from .zip and add to the foler
- Run the .py file inside the folder (This should create 2 .txt files)
- Open .txt files to observe results
